  Step 1: Install Dependencies
  ────────────────────────────────────────────────────────────────────────
  $ pip install -r requirements.txt
  
  Dependencies:
    • torch>=2.0.0
    • transformers>=4.30.0
    • sv-ttk>=2.6.0
    • mcp>=0.9.0
    • accelerate>=0.20.0
    • datasets>=2.14.0
    • huggingface_hub>=0.16.0

  Step 2: Train the Model
  ────────────────────────────────────────────────────────────────────────
  $ python luna_ai.py train --num-samples 5000 --epochs 2
  
  What happens:
    1. Loads SmolTalk2 dataset from HuggingFace
    2. Fine-tunes microsoft/DialoGPT-small
    3. Saves trained model to ./luna_model/

  Step 3: Use the Model
  ────────────────────────────────────────────────────────────────────────
  
  Option A - Chat GUI:
  $ python luna_ai.py chat
    • Opens Tkinter window
    • Dark theme by default
    • Real-time conversation
    • Export & clear functions
  
  Option B - MCP Server:
  $ python luna_ai.py mcp --port 8765
    • Starts API server
    • Exposes endpoints
    • External integrations
